# F Prime GDS Application

This app runs inside the cFS environment and bridges the cFS bus to the F Prime GDS using a built-in TCP server that runs on port 15010.

This allows developers familiar with the F Prime GDS to connect to the cFS bus and control cFS applications built with F Prime.

See [fprime_cfs](https://github.com/fprime-community/fprime_cfs) for more information on how to build cFS applications using the F Prime framework.
